# Project Statement [ROCK, PAPER AND SCISSORS]

## 1. Problem Statement

Rock Paper Scissors is a simple game, but playing it manually requires another person and keeping track of the score can be inconvenient.

The aim of this project is to make a simple Python-based version where a user can play against the computer. The computer makes its choice randomly and the program decides the winner based on the rules of the game. The program also keeps track of the score and match statistics and provites the final result along with the statistics.

## 2. Scope of the Project

The project is mainly focused on creating a simple command-line game using Python.

The current project includes:

1. Player vs computer gameplay
2. Best of 3, Best of 5 and Best of 7 matches
3. Random computer choices
4. Score tracking
5. Input validation
6. Match result
7. Basic statistics
8. Win percentage
9. Play Again option

The project is designed for terminal use and does not include a graphical interface and external libraries and gui.

## 3. Target Users

The main users of this project are:

* Students who want to understand basic Python programming
* Beginners learning programming through small projects
* Anyone who wants to play a simple Rock Paper Scissors game from the terminal with computer as opponent.

## 4. High-Level Features

### 1. Match Selection

The player can choose between Best of 3, Best of 5 and Best of 7 matches.

### 2. Player vs Computer

The player selects Rock, Paper or Scissor, while the computer makes a random choice.

### 3. Score Tracking

The program keeps track of the player's score and the computer's score during the match.

### 4. Input Validation

The program checks the player's choice and asks for a valid input when an incorrect option is entered.

### 5. Match Statistics

After a match, the program shows matches played, matches won, matches lost and the player's win percentage.

### 6. Play Again

After completing a match, the player can choose whether to play another match.
